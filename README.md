
# Cloud Migration & Solution Advisor

A Python-based assessment tool that analyzes application requirements, identifies common cloud migration risks, and provides preliminary Microsoft Azure service recommendations.

## Features

- Application requirement assessment
- Cloud-readiness scoring
- Risk identification
- Risk mitigation suggestions
- Azure service recommendations
- Migration roadmap
- Interactive Streamlit interface

## Technology Stack

- Python
- Streamlit
- Microsoft Azure
- Git/GitHub

## Application Workflow

Application Requirements
↓
Requirement Analysis
↓
Risk Assessment
↓
Cloud Readiness Score
↓
Azure Service Recommendations
↓
Migration Roadmap
